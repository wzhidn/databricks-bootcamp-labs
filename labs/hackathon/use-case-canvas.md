# Use-case canvas

Copy this file to `usecase-<team>.md` and fill it in.

| Box | Your answer |
|-----|-------------|
| **Outcome** — which decision or process improves, and for whom? | |
| **Users & channel** — who uses it, and where (Genie One, dashboard, app, agent)? | |
| **KPIs** — which measures prove success? Write them as metric-view measures (name + expression) | |
| **Data needed** — sources, owners, sensitivity tags | |
| **Acceptance criteria** — what must the 5-minute demo show? | |
| **Risks & guardrails** — privacy, cost, wrong answers; how do we control them? | |
| **Prototype link** — Genie App Builder or dashboard sketch | |

Example KPI: `revenue_at_risk = SUM(CASE WHEN churn_score > 0.7 THEN total_revenue END)`
