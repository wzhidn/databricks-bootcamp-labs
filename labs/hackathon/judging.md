# Judging criteria

Weights are a proposal — agree them with the sponsor before the event.

| Criterion | What judges look for | Weight | Score 1–5 |
|-----------|---------------------|:------:|:---------:|
| Business value | Clear outcome and KPI from the canvas; credible impact; the product owner can explain it | 25 % | |
| Governance | Data in Unity Catalog with correct permissions and tags; KPI defined as a metric view; PII masked | 20 % | |
| Engineering excellence | Shipped as a bundle **through CI to staging**; ≥ 1 unit test; expectations on new tables; no hardcoded IDs/secrets | 25 % | |
| Cost awareness | Serverless; tags on resources; sensible model choice through Unity Gateway; no idle compute | 10 % | |
| Demo quality | 5 minutes, working live, understandable to business and technical audiences | 20 % | |

**Tie-breaker:** the team whose pipeline run history shows a failed change caught at staging and fixed.
